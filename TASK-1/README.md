# Task 1: Identity and Access Management (IAM) Fundamentals

## Overview
This task focused on understanding the fundamentals of Identity and Access Management (IAM) and its importance in protecting enterprise systems, digital identities, and sensitive information.

## Objectives
- Understand digital identities and identity verification.
- Differentiate authentication and authorisation.
- Explore Single Sign-On (SSO) and the principle of least privilege.
- Understand how IAM strengthens enterprise cybersecurity.

## Key Concepts

### 1. Digital Identity
A digital identity represents a user within a system and contains identifying attributes used to manage access.

### 2. Authentication
Authentication verifies the identity of a user before granting access. Examples include passwords, biometrics, and Multi-Factor Authentication (MFA).

### 3. Authorisation
Authorisation determines which resources and actions an authenticated user is permitted to access.

### 4. Single Sign-On (SSO)
SSO allows users to access multiple connected applications through a single authentication process.

### 5. Principle of Least Privilege
Users should receive only the permissions necessary to perform their assigned responsibilities.

## Security Benefits
- Reduces the risk of unauthorised access.
- Improves control over user permissions.
- Supports audit trails and compliance.
- Helps reduce insider threats.
- Improves secure access across enterprise applications.
