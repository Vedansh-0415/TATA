# TCS Cybersecurity Analyst Job Simulation

**Platform:** Forage  
**Completed:** October 2026  
**Domain:** Cybersecurity — Identity and Access Management (IAM)

## Project Overview

Completed a virtual job simulation with Tata Consultancy Services (TCS), focused on evaluating and improving Identity and Access Management (IAM) for a hypothetical enterprise, TechCorp.

## Tasks and Deliverables

### Task 1: IAM Fundamentals
- Studied digital identity, authentication, authorisation, and Single Sign-On (SSO).
- Explored least privilege, access control, and IAM's role in enterprise security.

### Task 2: IAM Strategy Assessment
- Evaluated IAM readiness based on organisational requirements.
- Considered user lifecycle management, access controls, compliance, and system integration.
- Developed a practical checklist for assessing IAM readiness.

### Task 3: Custom IAM Solutions
- Designed solutions for secure user onboarding, role changes, and offboarding.
- Recommended Role-Based Access Control (RBAC), Multi-Factor Authentication (MFA), and least privilege.
- Considered scalability, usability, and alignment with business objectives.

### Task 4: Platform Integration
- Developed an IAM platform implementation plan.
- Addressed integration with legacy systems, third-party applications, and cloud services.
- Considered testing, phased deployment, monitoring, and optimisation.
