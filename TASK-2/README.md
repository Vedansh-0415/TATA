# Task 2: IAM Strategy Assessment

## Overview
This task focused on evaluating the IAM readiness of TechCorp Enterprises, a hypothetical global technology organisation undergoing digital transformation.

## Organisation Profile
- **Industry:** Information technology and services
- **Geographical reach:** More than 100 countries
- **Workforce:** Over 150,000 employees
- **Digital assets:** Proprietary software, enterprise systems, and data repositories

## Identified Challenges
- Increasing exposure to cybersecurity threats and data breaches.
- Complex user onboarding, role changes, and offboarding.
- Need for stronger access control mechanisms.
- Integration with legacy applications and cloud services.
- Need to improve operational efficiency and user experience.

## IAM Readiness Assessment Checklist

### 1. User Lifecycle Management
- [ ] Review employee onboarding and offboarding procedures.
- [ ] Evaluate automated account provisioning and de-provisioning.
- [ ] Verify that access is updated when employee roles change.
- [ ] Identify inactive and unnecessary accounts.

### 2. Access Control
- [ ] Review existing access control policies.
- [ ] Evaluate the use of Role-Based Access Control (RBAC).
- [ ] Verify implementation of least privilege.
- [ ] Identify excessive or inappropriate permissions.
- [ ] Assess MFA requirements for sensitive resources.

### 3. Compliance and Governance
- [ ] Review applicable regulatory and internal requirements.
- [ ] Evaluate access review procedures.
- [ ] Verify audit logging and reporting capabilities.
- [ ] Establish clear ownership of access policies.

### 4. Application Integration
- [ ] Inventory existing applications and systems.
- [ ] Identify legacy-system integration requirements.
- [ ] Assess support for standard authentication protocols.
- [ ] Review identity synchronisation and provisioning.

### 5. Cloud Integration
- [ ] Review cloud identity and access configurations.
- [ ] Evaluate centralised identity management.
- [ ] Assess access to cloud-hosted resources.
- [ ] Review privileged access and monitoring.

### 6. User Experience
- [ ] Evaluate login and authentication processes.
- [ ] Identify unnecessary manual access requests.
- [ ] Assess opportunities for SSO.
- [ ] Ensure security controls minimise unnecessary friction.

## Recommended Assessment Approach
1. Gather information about the organisation's users, systems, and business requirements.
2. Review existing IAM policies, controls, and workflows.
3. Identify security gaps and operational inefficiencies.
4. Prioritise risks based on business impact and security exposure.
5. Document findings and recommend improvements.
6. Develop a roadmap aligned with organisational objectives.

## Expected Outcome
A structured assessment framework for identifying IAM gaps and determining readiness for implementation.

## Important Note
This checklist is an assessment framework derived from the simulation scenario. Actual findings require evidence from the organisation's systems and processes; no real-world audit was conducted.
